# Getting help

**Something's broken.** Open a [bug report](https://github.com/ascendaone-com/ai-engineer-tools/issues/new/choose). Include the tool and its version, your OS, and the output of the tool's `doctor` command. Redact anything you don't want public.

**An agent isn't covered, or a hook payload changed.** Open a compatibility report or an integration proposal from the same issue chooser.

**You want to try it without an account.** [TESTING.md](./TESTING.md) runs everything against a local mock server, or against an event log on disk with `setup --no-pair`.

**You want to contribute.** [CONTRIBUTING.md](./CONTRIBUTING.md) covers building, testing and adding an adapter.

**A security problem.** Don't open a public issue. See the repository's Security tab for private reporting.
